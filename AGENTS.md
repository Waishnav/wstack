# Agent configuration

This repository contains configuration used by coding agents. Changes may alter behavior across projects, so keep them small and inspect their effective scope.

## Commit policy

- Never commit or push changes without explicit user approval.
- Make the requested changes, then show the relevant `git diff` and `git status`.
- When behavior requires user-side verification, ask whether it is working before offering to commit.
- Ask whether to commit and push unless the current request already explicitly authorizes those actions.
- Preserve unrelated local changes and never include them in a commit for the current task.
